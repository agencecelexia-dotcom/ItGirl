# Mon mois à Paris

Carnet de bord personnel, illustré, pour accompagner un mois d'installation
à Paris — pas un outil de productivité, un objet qu'on a envie d'ouvrir le soir.

## Stack

Vite + React 18 + TypeScript + Tailwind CSS v4.

## Développement

```bash
npm install
npm run dev
```

## État actuel

Étape 1 du plan de construction : squelette, navigation responsive, tokens
de direction artistique, carte-titre du jour. Les écrans Objectifs, Emploi
du temps, Lectures, Moodboard et Souvenirs sont des stubs en attendant les
étapes suivantes.
